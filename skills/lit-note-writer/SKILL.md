# lit-note-writer：精读笔记生成与入库

把结构化语料转成符合模板的 Obsidian 精读笔记。本环节承担全部学术提炼。

## 流程

### 1. 读取模板

模板路径：`<vault_root>/templates/论文精读模板.md`（本包附带模板文件；不存在则提示先初始化，禁止自造结构）。

### 2. Frontmatter 提炼（高度浓缩，禁止机械复制摘要）

| 字段 | 规则 |
| --- | --- |
| `title` / `author` / `year` / `source` | 取自元数据，原样 |
| `zotero_key` | 语料中的 item key，建立笔记↔Zotero 追溯链接 |
| `theme` | 一句话：论文主题 |
| `study_area` | 一句话：研究对象/研究区/样本范围 |
| `data_source` | 一句话：数据来源/样本/时间范围 |
| `methodology` | 一句话：核心方法/模型/识别策略 |
| `core_variable` | 一句话：核心变量/指标/概念 |
| `key_finding` | 一句话：最关键发现 |
| `relevance` | 一句话：对本研究的意义（唯一允许主观的字段） |

提炼标准：换一个人读 frontmatter 就能判断"这篇与我有关吗"。

### 3. 正文生成规则

- **研究方法区**：
  - 含公式时按"公式说明 + 公式 + 公式拆解"三段结构
  - 公式无法从语料可靠提取时，写"原文公式未能可靠提取，待补"，**禁止臆造**
  - 原文含乱码符号时，先尝试从上下文推断，仍不可靠则按待补处理
- **研究结论区**：每条结论 = "主要发现 n + 原文引用 n + 页码"成对结构，页码缺失时标注"页码未知"
- **过滤学术噪音**：作者单位、基金号、投稿规范、致谢、编辑评语等一律剔除
- 全篇中文撰写（英文术语可保留原文），语气客观，区分"论文说的"与"我判断的"（后者只进 `我的判断` 区）

### 4. 入库

- 路径：`<vault_root>/note/YYYY/作者姓-年份-短标题.md`（YYYY 为发表年，作者姓取第一作者；可按个人习惯调整归档目录）
- 使用文件系统直接写入（不走 MCP，长文本传输更稳）
- 已存在同名文件时：比对 frontmatter 的 `zotero_key`，同 key 视为重复，覆盖前先备份或询问

### 5. 返回

输出：笔记相对路径、zotero_key、一句话摘要、flags（fulltext_missing / annotations_empty 是否影响了成文质量）。

## 边界

- 不修改语料原始内容（引用必须忠于原文，宁缺毋滥）
- 不处理批量调度与进度记账（那是 lit-collection-manager 的职责）
